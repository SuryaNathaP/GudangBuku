# GudangBuku - Sistem Peminjaman Buku Perpustakaan

GudangBuku adalah aplikasi berbasis web yang dirancang untuk mempermudah manajemen perpustakaan dan proses peminjaman buku. Aplikasi ini membantu pustakawan dalam mengelola data siswa, koleksi buku, kategori, hingga pelacakan status peminjaman dan kalkulasi denda keterlambatan secara otomatis.

## 🚀 Fitur Utama

*   **Dashboard Informatif**: Menampilkan statistik total siswa, total buku, peminjaman aktif, aktivitas terbaru, serta menu aksi cepat.
*   **Manajemen Siswa**: Pengelolaan data siswa yang terintegrasi dengan NIS, Kelas, dan Jurusan.
*   **Manajemen Buku & Kategori**: Pelacakan stok buku, lokasi rak, serta pengelompokan buku berdasarkan kategori spesifik.
*   **Sistem Peminjaman & Pengembalian**: Pencatatan tanggal pinjam/kembali otomatis.
*   **Kalkulasi Denda Otomatis**: Mendeteksi keterlambatan pengembalian secara presisi dan menghitung akumulasi biaya denda yang harus dibayar.
*   **Manajemen Pengguna**: Pengaturan akun multi-user (Admin/Administrator) dengan kendali penuh.
*   **Antarmuka Modern**: Dilengkapi dengan dukungan Dark Mode/Light Mode yang responsif.

## 🛠️ Tech Stack

*   **Backend**: PHP (Laravel Framework)
*   **Frontend**: Blade Templates, Bootstrap
*   **Database**: MySQL
